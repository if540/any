把技能樹換成 115 年版規範的時候，順便把新增的 9 項讀了一遍。讀完的感想是：這次新增的準則都很「前端」，幾乎每一項都對得到一個常見的元件。

整理成五件我會先改的事。

**一、固定頁首要留空間給焦點**。固定頁首、Cookie 橫幅會把 Tab 到的連結整個蓋住，這是 2.4.11。一行 CSS 就能處理大部分情況：

```css
html { scroll-padding-top: 4rem; } /* 等於固定頁首的高度 */
```

**二、圖示按鈕至少 24px**。2.5.8 要求點擊目標至少 24×24 CSS 像素。圖示本身可以小，用 padding 把可點範圍撐大就好。分頁數字、標籤上的「×」、表格裡的小圖示最容易漏掉。

**三、能拖曳的地方，旁邊放按鈕**。2.5.7 要求拖曳的功能也能用點一下完成。拖曳排序加「上移」「下移」，看板卡片加「移到…」選單。這一項跟鍵盤操作是兩回事，鍵盤能用還不算過。

**四、表單不要讓人填第二次**。3.3.7 冗餘輸入：結帳時給「同收件地址」的勾選，多步驟表單把上一步的資料帶過來。順便把 `autocomplete` 屬性補齊，1.3.5 也一起顧到。

**五、登入頁不要擋貼上**。3.3.8 不允許只靠記憶或抄寫的認證方式，但只要讓密碼管理工具能自動填入、允許貼上，就有「協助的機制」。很多網站為了「安全」擋掉貼上，如果又沒有其他不考記憶的登入方式，就會不符合規範。

最後一個提醒：規範附件裡的 28 個軟體檢測碼，沒有一個對應到這 9 項新準則。自動檢測跑過全綠，不代表這些地方沒問題，還是要自己用鍵盤和手機實際操作一遍。
